# Record storage cutover

The live PostgreSQL path uses indexed `clinical_records`, rather than rewriting `workspace.data`. The original workspace is retained as a migration snapshot. The source-controlled `002_record_storage.sql` migration is applied by the new worker on the first authenticated record read. Its copy transaction locks the legacy workspace and marks completion atomically. A trigger rejects old-version writes after cutover.

Reads return 50 records per collection, plus referenced patients/orders. Settings, prices and custom tests have a bounded configuration page. Name-prefix and exact-ID search and cursor pagination run in PostgreSQL. Cloud patient counts and finance totals cover the complete database. Browser records, offline cache, and local CSV/JSON exports cover the loaded slice only; these exports are explicitly marked partial. Full database recovery requires database backup/restore management.

Writes carry changed rows and explicit deletions only. A transaction atomically advances the global revision with a compare-and-set check; a competing writer fails and rolls back. Validation, staff permissions, authorized result release, receipt uniqueness, and linked-record deletion checks still apply. Each save is capped at 200 changed records and 2 MB; this bounds a request, not the number of records in the database. A record can hold at most 1.5 MB; large imaging/attachment workloads still need object storage. There is no 10,000-patient total cap on the PostgreSQL path.

Verification uses a separate Neon branch with 300,000 synthetic patient rows. Run `npm run build`, then `node tests/capacity.postgres.mjs` and `node tests/capacity-safety.postgres.mjs`, supplying the isolated test connection through hidden stdin. Never run synthetic-record tests against production. Local tests cover delta construction, scoped deletion protection, excluded unchanged attachments, clinical permissions, email drafts, and offline merging. This is functional capacity evidence, not a concurrent-user performance or clinical commissioning certification.
